# Голосование на мероприятии

Ведущий, жюри и зал открывают приложение в браузере. Node.js ставить не нужно.

Постоянная ссылка — адрес опубликованного приложения. При публикации выберите доступ **Public**: иначе жюри и зал без аккаунта Cursor не откроют страницу.

1. Ведущий открывает постоянную ссылку и нажимает «Создать».
2. Кнопка «На главный» возвращает к списку. Имена и оценки остаются.
3. Вкладка «Ссылки»:
   - QR и ссылка жюри — на телефоны жюри
   - ссылка экрана — в браузер проектора
   - ссылка ведущего — только себе, чтобы снова открыть это же событие
   - «Сбросить имена и оценки» начинает событие заново. Ссылка ведущего остаётся.

Список событий и черновики живут в этом браузере. На другом телефоне список свой, пока туда не открыта ссылка ведущего. Имена участников, оценки и таймеры общие для всех, у кого есть ссылка. Имя жюри запоминается только на его телефоне.
