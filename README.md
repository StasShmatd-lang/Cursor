# Голосование на мероприятии

## Запуск на ноутбуке

Нужен [Node.js](https://nodejs.org/) 18+ (лучше 22 LTS).

```bash
npm run install:all
npm run dev
```

Откройте в браузере: **http://127.0.0.1:5173**

- `/` — ведущий  
- `/vote/:id` — жюри  
- `/screen/:id` — экран зала  
- `/prep/:id` — подготовка спикера  

API и сокеты: порт **3001** (проксируется через Vite при dev).
